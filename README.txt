UNTITLED — interactive screenplay website
Author: Panchangam Sameera

FILES
- index.html : complete responsive screenplay experience
- assets/time.mp3 : optional local audio slot for Pink Floyd — Time

AUDIO
The page is already wired to the screenplay's music cues:
- 2:09 (129s): Rishi puts in earbuds / montage begins
- 4:00 (240s): ride home section
- 6:01 (361s): home section

Because the song is copyrighted, the audio file itself is NOT included.
If you have a lawful local copy, name it exactly: time.mp3
and place it inside the assets folder next to index.html.

HOSTING
This is static and GitHub Pages-ready. Upload index.html plus the assets folder.

DESIGN INTENT
- icy blue, comforting rather than cold
- sparse background snowfall
- smooth scroll reveals
- screenplay-style character/dialogue hierarchy
- visual emotional pivot at the washroom confession
- Rishi's music is treated as subjective sound
- responsive across phone/tablet/laptop/desktop
